# Teste de Digitação

Site para medir a velocidade de digitação, no estilo do 10FastFingers. O texto é gerado com palavras aleatórias, e no fim do tempo o site mostra as palavras por minuto (WPM), os acertos, os erros e a precisão.

## Funcionalidades

- Três modos de jogo: fácil (60 s), médio (45 s) e difícil (30 s)
- Palavras em português, inglês e espanhol
- Destaque em tempo real das letras certas e erradas
- Cálculo de WPM e de precisão
- Botão para reiniciar

## Como usar

Abra o `index.html` no navegador e comece a digitar. O tempo começa a contar na primeira tecla.

## Tecnologias

HTML, CSS e JavaScript puro.
